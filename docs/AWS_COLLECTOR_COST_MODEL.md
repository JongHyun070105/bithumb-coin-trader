# AWS Market Data Collector Cost Model

## 1. 개요 및 비용 산정 기준 (Overview & Assumptions)

본 문서는 AWS 아시아 태평양(서울, `ap-northeast-2`) 리전에서 실행되는 시장 데이터 수집 인프라의 런타임 기간별 비용 모델을 정의한다.

### 1.1 기본 리소스 및 단가 기준 (Pricing Baseline - ap-northeast-2)

1. **EC2 컴퓨팅 (Compute)**:
   - 인스턴스 타입: `t3.medium` (2 vCPU, 4.0 GiB RAM)
   - 온디맨드 단가: **$0.0416 / 시간**
2. **EBS 스토리지 (Root Block Storage)**:
   - 볼륨 타입: `gp3` 200 GiB (기본 3,000 IOPS, 125 MB/s 무료 포함)
   - 단가: **$0.080 / GB-월** (200 GiB 기준 월 $16.00, 즉 시간당 약 **$0.0219 / 시간**)
3. **퍼블릭 IPv4 주소 (In-use Public IPv4)**:
   - 단가: **$0.005 / 시간**
4. **CloudWatch 모니터링 및 로그**:
   - Custom Metrics: 3개 지표 (시간당 3 지표 × $0.30/월 = 월 $0.90, 시간당 약 $0.0012)
   - Log Ingestion: 시간당 약 50 MB 발생 가정 = 약 1.2 GB/일 = $0.50 / GB 기준 일 약 $0.60
5. **S3 아카이브 스토리지**:
   - 시간당 생성 압축 ZST 데이터: 시간당 약 76개 파티션, 약 150 MB/시간 (일 약 3.6 GB)
   - S3 Standard 스토리지 단가: **$0.023 / GB-월**
   - PUT 요청 단가: 1,000건당 **$0.005** (시간당 76건 = 하루 1,824건 = 일 약 $0.009)

## 3. 비용 민감도 분석 및 용량 확장성 (Cost Drivers & Scaling Implications)

1. **EBS vs S3 비용 효율성**:
   - EBS gp3는 GB당 $0.08/월인 반면, S3 Standard는 GB당 $0.023/월로 약 3.5배 저렴하다.
   - 장기 실행(8주~12주) 시에는 로컬 디스크 원본을 무한정 쌓지 않고, 폐쇄 시간대(Closed Hour) 아카이브 검증이 완료된 RAW 데이터를 안전 정책에 따라 정리(Lifecycle)함으로써 EBS 용량을 200 GiB 고정으로 유지하는 것이 비용 최적화의 핵심이다.
2. **네트워크 데이터 전송(Data Transfer)**:
   - 외부 웹소켓 수신(Ingress)은 AWS 정책상 전액 무료이다.
   - CloudWatch 메트릭 및 S3 내부 전송(VPC Endpoint 미사용 시에도 동일 리전 내 무료 또는 극소액) 비용 영향은 무시할 수 있는 수준이다.
3. **결론**:
   - 72시간 소크의 총 인프라 비용은 약 **$7 미만**으로 매우 경제적이며, 1개월 전체 연속 운영 시에도 약 **$70 내외**로 유지된다.
