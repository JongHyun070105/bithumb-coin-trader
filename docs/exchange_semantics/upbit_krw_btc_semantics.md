# 업비트(Upbit) KRW-BTC 마이크로스트럭처 의미론 및 사양서

## 1. 개요
본 문서는 국내 최대 거래소인 업비트(Upbit)의 KRW-BTC 마이크로스트럭처 특성을 정의한다.

## 2. 호가 단위 및 시장 사양
- 마켓 심볼: `KRW-BTC`
- 가격 호가 단위(Tick Size): 1,000 KRW
- 수량 최소 단위: 0.00000001 BTC
- 최소 주문 금액: 5,000 KRW
- 기본 거래 수수료: 0.05% (5 bps)

## 3. 웹소켓 피드 및 데이터 의미론
- 구독 타입:
  - `orderbook`: 15레벨 호가창 스냅샷
  - `trade`: 체결 틱 데이터 (ask_bid 체결 구분)
- 타임스탬프 의미론:
  - `timestamp`: 거래소 체결/호가 타임스탬프 (밀리초)
  - `trade_timestamp`: 체결 고유 시각

## 4. 빗썸과의 상호작용
- 빗썸과 업비트는 동일한 KRW 기반 유동성 풀을 공유하며, 두 거래소 간 최우선 호가는 대부분 1~2틱(1,000~2,000 KRW) 이내에서 차익거래 봇들에 의해 동기화됨.
