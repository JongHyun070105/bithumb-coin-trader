# 빗썸(Bithumb) KRW-BTC 마이크로스트럭처 의미론 및 사양서

## 1. 개요
본 문서는 빗썸(Bithumb) 거래소의 KRW-BTC 현물 마켓 데이터 수집, 호가창(Order Book), 체결(Trade) 및 주문 실행 특성을 정의한다.

## 2. 호가 단위 및 시장 사양
- 마켓 심볼: `KRW-BTC` (또는 내부 코드 `BTC_KRW`)
- 가격 호가 단위(Tick Size): 1,000 KRW (BTC 가격이 100,000,000 KRW 구간일 때 1,000 KRW 단위, 0.001%)
- 수량 최소 단위(Lot Size): 0.0001 BTC
- 최소 주문 금액: 5,000 KRW
- 기본 거래 수수료율:
  - 테이커(Taker): 0.04% (쿠폰 적용 기준) ~ 0.25% (기본 요율)
  - 메이커(Maker): 0.04% ~ 0.25%
  - 연구 기본값(Conservative): 0.04% (4 bps)

## 3. 웹소켓 피드 및 데이터 의미론
- 구독 채널:
  - `orderbookdepth`: 30레벨 호가창 스냅샷/델타 피드
  - `transaction`: 실시간 체결 틱 데이터
- 타임스탬프 의미론:
  - `datetime`: 거래소 서버 내부 이벤트 발생 시각 (밀리초 또는 마이크로초 문자열)
  - `received_at`: 로컬 수집기 수신 시각 (monotonic clock 결합)
- 호가창 갱신 특성:
  - 스냅샷 주기: 약 50ms ~ 200ms 비정기적 브로드캐스트
  - 버퍼링 및 지터: 네트워크 상태에 따라 간헐적 100ms~500ms 버스트 전송 관측

## 4. 체결 시뮬레이션 시 주의사항
- Bithumb은 국내 소매 투자자 비중이 높아 모멘텀 돌파 시 슬리피지가 급격히 증가하는 씬 북(Thin Book) 레짐이 빈번함.
- 호가 뎁스 소비 시 상위 3레벨(약 1~3 BTC)을 초과하는 주문은 비선형적인 시장 충격 비용(Market Impact)을 유발함.
